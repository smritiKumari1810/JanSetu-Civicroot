# JanSetu + CivicRoot AI

**From Citizen Complaints to Preventive Governance**

This repository contains the codebase for the JanSetu and CivicRoot AI platform.

## Overview
- **JanSetu (Citizen Layer):** Simpler reporting, smart routing, persistent complaint history, and citizen updates.
- **CivicRoot (Intelligence Layer):** Connects similar complaints, detects recurring hotspots, predicts risk, and recommends preventive action.

*Note: This project is currently in the initial setup phase.*
